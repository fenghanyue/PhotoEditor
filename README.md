# 照片水印（PhotoEditor）

一个自用的安卓 App：把照片自带的拍摄信息（时间、机型、镜头、焦距、光圈、快门、ISO）和位置印到照片上，另存为新图，原图不动。

## 安装

- **正式版（推荐）**：用手机浏览器打开 [Releases 里的最新正式版](https://github.com/fenghanyue/PhotoEditor/releases/latest)，下载 APK 后直接安装。
- **测试版**：[最新测试版](https://github.com/fenghanyue/PhotoEditor/releases/tag/latest-dev) 是正在开发的代码，每次推送都会自动重新编译，可能有问题。

第一次安装时，需要允许浏览器"安装未知应用"。新版本可以直接覆盖安装旧版本；如果装过更新的测试版，再装较早的正式版会提示安装失败，要先卸载。

App 首页会显示版本号：正式版如 `0.4.0`，测试版后面带编译序号，如 `0.4.0-build15`。每个版本改了什么见[更新记录](CHANGELOG.md)。

## 怎么用

在相册里点一张照片，进入"加水印"页：选模板（参数边框 / 信息叠加），调好选项，点"保存到相册"。新图存在 `Pictures/PhotoEditor/`，文件名后面加 `_wm`，原图不动。右上角的 ⓘ 可以查看照片里读出来的全部信息。

机型名称（参数边框）：

- "手动输入"：先填入照片识别出的名称，可以自己修改。
- "选择机型"：在弹层里选 相机/手机，再点开品牌、型号的下拉列表。即使只有一个选项也可以展开。首批支持 尼康 Z5 II 和 一加 15T，水印分别显示 `Nikon Z5 II`、`OnePlus 15T`。
- 品牌和型号选好后，点底部"确定"才把名称和品牌标识一起应用到水印。型号没选完整时不能确定；关闭、返回或点弹层外部会放弃本次修改。切换设备类型后需要重新选择品牌和型号。
- 选择模式下点"更换"可以重新选择；想输入文字，先切回"手动输入"。两种方式分别保留内容，取消弹层不会覆盖原来的设置。
- 本次运行里，按照片原始的品牌和型号分别记住输入方式、手填名称和已选机型；关闭 App 后的保存还在待办中。

拍摄参数（0.4.1 测试版）：

- 点“拍摄参数”旁的“编辑”，自动带入这张图的原始记录。曝光补偿、光圈用下拉选择；ISO、实际／等效焦距和快门可输入，快门支持 `1/250` 或 `0.5` 秒。
- 点“确定”才应用，关闭弹层放弃草稿；“恢复原值”也需点确定。原图不在预设档位中的值会保留，切换照片不会串用参数。
- 水印优先显示等效焦距，没有时用实际焦距；参数行显示已记录的曝光补偿。修改的是参数记录，画面亮暗和虚化不随之改变。
- 保存时将修改写进新 JPEG 的拍摄信息，再重新读取核对，原文件保留。截图没有的参数显示“未记录”，可以补填；留空则不写入。
- 光圈列表保留常用档位和原图值，已知尼康 24–200mm 镜头的两端按官方范围列出；中间焦段不推测完整光圈曲线。PNG 截图仍按现有流程另存为 JPEG。

档位与镜头范围参考：[Z5II 曝光控制步长](https://onlinemanual.nikonimglib.com/z5II/en/csmb_ev_steps_for_exposure_cntrl_222.html)、[NIKKOR Z 24–200mm 镜头规格](https://onlinemanual.nikonimglib.com/z5/en/16_kit_lens_manual_02.html)。

地区（不用联网）：

- 带 GPS 的照片，按 GPS 自动查出省、市、区县；GPS 在国外或海上时查不到，只印坐标。
- 没有 GPS 的照片（比如相机拍的），沿用上一张照片的地区。
- 点"选择"可以搜索（比如"敦煌"），或者按 省 → 市 → 区县 逐级选。
- 地区后面可以再填一个地点名称，印出来是"甘肃省敦煌市 · 鸣沙山月牙泉"。写法可以选"省+区县""省市区"或"只写区县"。

## 自己编译

需要 JDK 17 以上和 Android SDK（compileSdk 37）：

```
./gradlew assembleRelease
```

APK 在 `app/build/outputs/apk/release/` 下。

本地测试包需要覆盖已安装的版本时，可传入 `-PlocalVersionCode=版本序号`，序号取大于已安装版本的值。GitHub 自动编译仍使用 Actions 的编译序号。

## 发版本

1. 把 `app/build.gradle.kts` 里的 `appVersion` 改成新版本号，在 `CHANGELOG.md` 里写好这一版的说明。
2. 准备正式发布时，把 `.github/release-version` 改成同一个版本号（如 `0.4.1`），随代码一起合并到 `main`。
3. Actions 会自动编译、运行单元测试和代码检查；全部通过后打标签 `v0.4.1`，在 Releases 发布 APK，更新说明取自 `CHANGELOG.md`，不需要再点网页按钮。

普通提交和开发分支只编译，不发正式版。版本号必须和 `appVersion` 一致，并有对应的更新说明；已发布且 APK 完整的版本会跳过，不覆盖已有安装包。若只有标签、草稿或不完整的发布记录，流程会报错，需先检查处理。

手动入口仍保留：Actions → 编译 APK → Run workflow，分支选 `main`，版本号填 `0.4.1` 这样的格式；留空只编译。临时故障可重新运行原任务；若修改了代码，需在新代码合并后用手动入口重试同一版本，因为重跑原任务仍会使用原提交。

## 注意

`app/debug.keystore` 是公开的测试签名，只是为了让每个新版本都能直接覆盖安装。不要用它签名要发给公众的 App。

## 字体、Logo 和地区数据的来源

- 水印字体是思源黑体（Noto Sans SC）的常用字子集，使用 SIL Open Font License 1.1，授权文本见 `app/src/main/assets/fonts/OFL.txt`。子集由 `tools/fonts/subset_noto_sc.py` 生成。
- 尼康 Logo 来自 Wikimedia Commons（File:Nikon_Logo.svg），在版权上属于公有领域，商标归尼康所有，这里只用于个人照片水印。
- 省、市、区县的边界来自阿里云 DataV.GeoAtlas，由 `tools/regions/build_regions.py` 下载并压缩成 `app/src/main/assets/regions.bin`，只用于这个自用 App 离线查地区，数据版权归原提供方所有。地名用到的生僻字（如"埇""鄠"）也收进了字体。
